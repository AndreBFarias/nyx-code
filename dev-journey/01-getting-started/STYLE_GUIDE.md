# Nyx-Code - Guia de Identidade Visual e UX

## Filosofia

Nyx vive no terminal. Cada interação é precisa, direta, sem desperdício.
A estética é cyberpunk de terminal: escuro, elegante, funcional.

Zero emojis. Zero verbosidade. Zero linguagem corporativa.

## Paleta de Cores (Dracula Gothic)

```
BACKGROUND
  background-main:     #282a36
  background-elevated: #44475a

FOREGROUND
  text-primary:        #f8f8f2
  text-secondary:      #6272a4

ACCENT
  purple-primary:      #bd93f9   (cor principal Nyx)
  pink:                #ff79c6   (alertas, destaque)
  green:               #50fa7b   (sucesso, código)
  cyan:                #8be9fd   (info)
  orange:              #ffb86c   (avisos)
  red:                 #ff5555   (erros)
```

## Tom de Voz

- Técnico, direto, preciso
- Frases curtas
- PT-BR sem formalismos
- Formato: diagnóstico -> solução -> verificação

## Tags de Output

| Tag | Cor | Uso |
|-----|-----|-----|
| `[nyx]` | purple | Mensagens do sistema |
| `[nyx]` | green | Sucesso |
| `[nyx]` | orange | Avisos |
| `[nyx]` | red | Erros |

## Interface

- Banner com ASCII art no boot
- Informações de status: modelo, portas, VRAM
- Mensagens curtas em PT-BR
- Citação de filósofo no fim de cada script
