- **Nenhuma menção a IA** (ADR-005) — exceto uma docstring em `output.py:302` ("estilo Claude Code").

  1. **Fonte única de verdade ausente** (portas, cores, modelo — N-para-N em 7+ lugares).

## Críticos (bloqueia release / Onda 22)

### [C-01] Serviço `compact` tem zero consumidores — código morto

- **Arquivo:** `nyx/agent/services/compact.py`
- **Sintoma:** `grep -r "from nyx.agent.services.compact" --include='*.py'` retorna 0 resultados fora do próprio arquivo.
- **Causa provável:** service criado em port de OpenClaude, integração nunca completada.
- **Violação:** ADR-013 (Integração Obrigatória) — "tudo no registry/commands/services/consumidores".
- **Fix proposto:** ou (a) remover `compact.py` se não for mais necessário, ou (b) plugar no `AgentLoop.maybe_summarize` como etapa opcional.
- **Sprint:** `AUDIT-FIX-01`

### [C-02] `NyxSettings` e `settings.py` órfãos

- **Arquivo:** `nyx/config/settings.py`
- **Sintoma:** `grep -r "from nyx.config.settings\|import NyxSettings"` retorna 0 resultados em produção.
  - Apenas `nyx/proxy.py` e `nyx/agent/loop.py` importam de `nyx/config/defaults.py` (algumas constantes soltas).
  - `load_settings()` e a dataclass nunca são usadas.
- **Causa:** camada de config planejada foi escrita mas nunca conectada ao bootstrap em `cli.py` / `run.sh`.
- **Impacto:** toda mudança de config exige editar N arquivos; `.env` é lido por `load_dotenv` mas resultado não propaga.
- **Violação:** ADR-013 (Integração Obrigatória); N-para-N potencial.
- **Fix proposto:** `cli.run_repl` passa a receber `NyxSettings`, propaga pra `AgentLoop` e `proxy`. Variáveis de ambiente passam a ter fonte única.
- **Sprint:** `AUDIT-FIX-02`

### [C-03] Portas `11435` / `11436` hardcoded em 15+ pontos (N-para-N)

- **Arquivos afetados:**
  - `nyx/cli.py:53, 54, 217, 220, 557, 560`
  - `nyx/proxy.py:38, 283, 284`
  - `nyx/providers/ollama.py:18`
  - `nyx/agent/loop.py:99`
  - `nyx/agent/commands.py:247, 249, 253, 258, 260, 263, 442, 444, 635`
- **Sintoma:** mudar porta → editar 15 lugares manualmente.
- **Causa:** `config/defaults.py:OLLAMA_PORT=11435` existe mas nenhum arquivo o usa para o literal `11435`.
- **Violação:** meta-regra N-para-N (inviolável).
- **Fix proposto:** todos os módulos passam a importar `from nyx.config.defaults import OLLAMA_PORT, PROXY_PORT`. Adicionar `PROXY_PORT = 11436` em `defaults.py`. Refatorar `f-strings`.
- **Sprint:** `AUDIT-FIX-03` (deve executar antes de qualquer sprint de deploy)

### [C-04] Exceção silenciosa em `cli.py:509-512`

- **Arquivo:** `nyx/cli.py:509-512`
- **Trecho:**
  ```python
  try:
      asyncio.create_task(agent.maybe_summarize())
  except RuntimeError:
      pass
  ```
- **Sintoma:** se `create_task` falhar (loop fechado, etc.) a sumarização silenciosamente é perdida. Contexto pode overflow sem feedback.
- **Violação:** CLAUDE.md "Nunca except vazio — todo except deve ter logger.error() ou raise".
- **Fix proposto:** `logger.warning("sumarização adiada: %s", e)` antes do pass.
- **Sprint:** `AUDIT-FIX-04` (trivial, 2 linhas)

## Altos (prioriza na Onda 22)

### [A-01] `agent/commands.py` violou limite de 800 linhas (atual: 919)

- **Arquivo:** `nyx/agent/commands.py`
- **Sintoma:** 919 linhas, ultrapassa ADR de limite de 800.
- **Violação:** CLAUDE.md "800 linhas por arquivo (exceções: config, testes, registries)". `commands.py` não é registry puro — tem lógica de implementação.
- **Fix proposto:** dividir em `commands/__init__.py`, `commands/git.py`, `commands/session.py`, `commands/debug.py`, `commands/context.py`. Manter API `handle_command()` e `list_commands()`.
- **Sprint:** `AUDIT-FIX-05` (refactor amplo, isolado de UX)

### [A-02] `output.py` usa `print()` em 10+ pontos

- **Arquivo:** `nyx/agent/output.py:306, 344, 373, 375, 376, 400, 401, 406, 439, 457`
- **Sintoma:** camada de render imprime direto em stdout.
- **Violação:** CLAUDE.md "print() apenas no cli.py". Mas pragmaticamente `output.py` É uma camada de rendering; pode ser aceitável **se registrado como exceção no ADR**.
- **Fix proposto:** duas opções:
  - (a) criar `ADR_024_RENDER_LAYER.md` normalizando `output.py` como exceção oficial.
  - (b) todas as funções viram retornos de string; `cli.py` faz o print. Mais puro, mais invasivo.
- **Recomendação:** opção (a) — ADR explícita. A camada de render precisa escrever.
- **Sprint:** `AUDIT-FIX-06`

### [A-03] `ask_user.py:68` usa `print()` — tool que renderiza

- **Arquivo:** `nyx/agent/tools/ask_user.py:68`
- **Sintoma:** tool do agent usa `print()` direto pra exibir pergunta.
- **Violação:** CLAUDE.md e ADR-013 — tool deve retornar `ActionResult`, quem renderiza é o loop/cli.
- **Fix proposto:** tool devolve pergunta no `ActionResult.output`; cli.py renderiza via `render_prompt(question, options)`.
- **Sprint:** `AUDIT-FIX-07`

### [A-04] Hex de cores duplicados em `cli.py` e `output.py` (N-para-N)

- **Arquivos:** `cli.py:41-45` e `output.py:30-32, 304, 340, 371, 397, 427, 454` (e mais).
- **Sintoma:** `#00D4AA` aparece hardcoded em 8+ pontos. Escapes ANSI `\033[38;2;0;212;170m` repetidos.
- **Violação:** N-para-N.
- **Fix proposto:** **É o trabalho da `UX-DESIGN-01`** (já no plano) — criar `nyx/themes/design_tokens.py` e refatorar imports. Este item só valida o escopo dela.
- **Sprint:** **absorve para UX-DESIGN-01** (já existe no plano, não cria novo).

### [A-05] Docstring menciona "Claude Code" em `output.py:302`

- **Arquivo:** `nyx/agent/output.py:302`
- **Trecho:** `"""Imprime tool call estilo Claude Code: '⏺ nome(arg)' em accent color."""`
- **Violação:** ADR-005 (Anonimato).
- **Fix proposto:** reescrever docstring sem menção: `"""Renderiza linha de tool call com bullet ⏺ em accent color."""`.
- **Sprint:** `AUDIT-FIX-08` (trivial, 1 linha)

### [A-06] Emoji `⚡` (U+26A1) em `cli.py:88, 195`

- **Arquivo:** `nyx/cli.py:88, 195`
- **Sintoma:** `⚡ bypass · ...` e `⚡ bypass permissions ON`.
- **Violação:** ADR-004 (Zero Emojis). Tecnicamente ⚡ é Unicode "Miscellaneous Symbols" — é emoji em fonts modernas.
- **Fix proposto:** substituir por `[!]` ou `⋅⋅⋅` ou deixar apenas texto. Decisão de design (UX-DESIGN-01 define glifos oficiais).
- **Sprint:** **absorve para UX-DESIGN-01** (decisão de glifos canônicos).

### [A-07] `on_token` compete com spinner — flicker

- **Arquivo:** `nyx/cli.py:244-248`
- **Sintoma:** streaming escreve em `sys.stdout` sem parar spinner primeiro em 100% dos caminhos. `_stop_spinner()` é chamado mas o flush do spinner pode colidir com os primeiros tokens.
- **Observação:** já há mitigação (chamada explícita `_stop_spinner` em `on_token`), mas resíduo pode permanecer por 1 frame.
- **Fix proposto:** esvaziar linha do spinner com `\r\x1b[2K` antes de escrever token. Absorvido em **UX-LAYOUT-03** (já planejada).
- **Sprint:** **absorve para UX-LAYOUT-03**.

### [A-08] `asyncio.create_task` sem cancelamento ao quit

- **Arquivo:** `nyx/cli.py:509-512`
- **Sintoma:** task de sumarização fica pendurada; ao sair, pode gerar `RuntimeWarning: coroutine never awaited` ou corromper sessão salva.
- **Fix proposto:** manter handle da task, cancelar antes do `save_session` no fim da função.
- **Sprint:** **absorve para UX-BUG-03** (perf/responsividade inclui cleanup).

### [A-09] `Console(highlight=False)` criado por render, não singleton

- **Arquivo:** `nyx/agent/output.py:379` (dentro de `render_user_input`)
- **Sintoma:** cada render de user input instancia novo `Console()`. Caro em CPU.
- **Fix proposto:** singleton `_get_console()` lazy em `output.py`.
- **Sprint:** **absorve para UX-BUG-03** (perf).

### [A-10] `USER_INPUT_COLLAPSE_LINES=8` colapsa perdendo contexto intermediário

- **Arquivo:** `nyx/agent/output.py:347, 364-366`
- **Sintoma:** input de 9 linhas colapsa para 3 primeiras + "[6 linhas ocultas]". Usuário não vê últimas linhas, que costumam ter a pergunta.
- **Fix proposto:** colapsar para 3 primeiras + 2 últimas + "[N linhas ocultas no meio]", ou oferecer `/paste` para ver completo.
- **Sprint:** **absorve para UX-LAYOUT-01** (banner + boxes incluem esse tratamento).

## Dívida técnica (Onda 23+)

### [D-01] `loop.py` 739 linhas, próximo do limite

- Não urgente, mas fragmentar em `loop/core.py`, `loop/parsing.py`, `loop/state.py` seria saudável.

### [D-02] Sistema de temas (`nyx/themes/entities/*.json`) não é consumido por `output.py`

- **Sintoma:** `ThemeManager` carrega cores via `hex_to_ansi_raw` mas `output.py` ignora e usa escapes ANSI hardcoded.
- **Fix futuro:** `output.py` consome `ThemeManager.get_ansi_colors()` dinamicamente; `design_tokens.py` torna-se fallback estático.

### [D-03] `nyx/interface/__init__.py` é vazio — diretório órfão

- Ou deletar, ou popular (futuro: front-end web/TUI alternativo).

### [D-04] `proxy.py` menciona "Anthropic" em 3 docstrings

- Contexto: tradução de protocolo; é necessário para documentar a conversão. Não é violação real de ADR-005 (strings técnicas permitidas). Manter.

### [D-05] `logging_service.py` só tem 1 consumidor (`cli.py`)

- Se é infraestrutura central, todos os módulos deveriam chamar `InternalLogging()`. Hoje cada módulo faz `logging.getLogger(...)` solto — padrão aceitável mas inconsistente.

## Oportunidades de UX (além do pedido original)

- **[O-01]** Barra de progresso visual para operações longas (moondream vai precisar).
- **[O-02]** `/help` com busca fuzzy (hoje é lista estática).
- **[O-03]** Indicador visual de "qwen3 está cold" na primeira request (warm-up leva 5-15s, usuário acha que travou).
- **[O-04]** Confirmação visual quando sessão é salva automaticamente ao quit (hoje silencioso).

- **[O-06]** `ctx %` no toolbar não mostra qual limite (4096? 8192?). Falta `X%/max` ou `Ntok/Mtok`.
- **[O-07]** Feedback do que foi sumarizado quando compactação automática roda.
- **[O-08]** Ctrl+C durante streaming deixa resíduo de texto; precisa `\x1b[2K\r` pra limpar.
- **[O-09]** Sem atalho para editar o último user input (como `!!` do bash ou seta-pra-cima com edição).
